# 対象選定に人間の承認を置かず、方針だけを人間が所有する

対象は方針（installs閾値、更新の生存、攻撃面、プログラム適合）から機械的に選び、予算内で上から回す。Approved Target Batchのような人間の事前承認は持たない。公開事例（Mythos、Carlini、XBOWの対象採点）は対象を機械的に広く取り、人間の承認を探索の入口に置かない。数をこなす収益モデルでは承認が律速になり、判断者自身が承認の質を担保できないと述べているため。安全は既存のoracle-free入力と隔離が担う。重複リスクの重み付けはしない（triagerが決める）。
