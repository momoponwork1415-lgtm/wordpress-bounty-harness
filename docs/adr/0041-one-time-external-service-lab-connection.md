# 外部サービス接続を要する手動検証の一回限りの例外を記録する

## 背景

ある手動検証では、対象プラグインが実サービスに接続した状態を確認する必要があった。通常の Lab は内部ネットワークだけで動き、外向き通信は provider API に限る。所有者は 2026-10-26、この一件に限って専用 `runsc` Lab から対象サービス API への通信と、無害な接続確認中だけの一時公開 URL を明示承認した。対象、Finding、資格情報、画面、HTTP 記録は Git 外の Private Evidence に置く。

## 決定

- この承認は一件の手動実験にだけ適用する。本番ランナー、探索 Trial、通常の検証 Lab のネットワーク既定値は変えない。別の対象や再試行に流用しない。
- WordPress と対象プラグインは専用の使い捨て `runsc` Lab 内だけで実行する。外向き通信は接続に必要なサービス API の固定ホスト・ポートに絞った中継器を通し、通信を記録する。任意の宛先への直接通信は許可しない。
- 一時公開 URL は接続確認中だけ使う。公開入口は無害な `GET` / `HEAD` の確認用パスだけを通し、管理画面、ログイン、REST、投稿、コメント、任意のアップロードを拒む。
- 攻撃入力を置く前に公開入口とサービス API 向けの出口を停止し、外部から到達できないことを確かめる。以後の操作と観測は Lab 内だけで行う。入口を再開して攻撃入力を公開しない。
- 資格情報と実施記録は Private Evidence に置く。接続成功そのものや AI の観測を、`review observe` の人間の `match` や `review decide --reproduced match` に読み替えない。確定は SPEC §2(3) と ADR 0040 に従う。

## 実施と終了

2026-10-27 にこの一件の接続確認と内部 Lab での観測を行い、公開入口、出口、Lab を停止・削除した。公開入口の停止は外部からの再確認でも確かめた。接続処理は Lab 内から直接呼び出しており、管理画面の通常 UI による接続は確認していない。実施計画、接続応答、観測、停止確認は Private Evidence に保存した。サービス側の一時許可ドメイン削除と資格情報の扱いは、アカウント所有者のログイン後に完了させる。ここに書いた承認は実験終了とともに失効し、次の Lab へは引き継がない。

## 採らなかった選択肢

- 通常 Lab の外向き通信を恒久的に広げる: 今回の接続確認以外に根拠がない。
- 一時公開 URL を攻撃入力後も維持する: 公開範囲が不要に広がる。
- AI の画面観測だけで再現確定とする: SPEC §2(3) の人間の記録がない。

## 消し方

この ADR と SPEC・DEVELOPMENT の参照を revert する。Git 外の実施記録は既存の保存方針に従って保持する。
